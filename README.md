# natsustan/homebrew-tap

Homebrew casks for apps by natsustan.

## Prism

A keyboard launcher for macOS 26 and later on Apple silicon.
[prismformac.com](https://prismformac.com)

```sh
brew install --cask natsustan/tap/prism-app
```

Prism updates itself through Sparkle, so the cask is marked
`auto_updates true` and `brew upgrade` leaves it alone. To force a
Homebrew-managed reinstall:

```sh
brew upgrade --cask --greedy prism-app
```

Uninstall, optionally removing settings and data:

```sh
brew uninstall --cask prism-app
brew uninstall --cask --zap prism-app
```

Casks here are generated by Prism's release script; do not edit them by hand.
